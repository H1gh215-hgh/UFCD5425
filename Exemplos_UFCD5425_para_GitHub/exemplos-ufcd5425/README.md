# Exemplos de projeto — UFCD 5425

Quatro versões de um exercício semelhante (gestão de contactos ou
tarefas), em quatro tecnologias diferentes, por ordem crescente de
complexidade. Fazem parte do manual de apoio da UFCD 5425 — Projeto de
Tecnologias e Programação de Sistemas de Informação (ver Anexo A do
manual para a explicação detalhada de cada um, com trechos de código
comentados).

| Pasta | Tecnologia | Nível |
|---|---|---|
| [`scratch/`](scratch/) | Scratch (programação em blocos) | Inicial |
| [`contactosfacil/`](contactosfacil/) | HTML, CSS e JavaScript | Inicial/intermédio |
| [`tarefafacil/`](tarefafacil/) | Python (Flask) + SQLite | Intermédio |
| [`agendac/`](agendac/) | C | Avançado |

Cada pasta tem o seu próprio `README.md` com instruções de como abrir
ou executar esse exemplo.

## Como obter os ficheiros (alunos)

**Sem usar git** — mais simples, recomendado para quem está a começar:
no topo desta página, clicar no botão verde **Code** e depois em
**Download ZIP**. Extrair o ficheiro descarregado para ver todas as
pastas.

**Com git** — para quem já está a aprender a usar o git:

```bash
git clone <endereço deste repositório>
```
